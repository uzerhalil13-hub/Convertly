# Convertly 📱🔄

A powerful, fully offline media format converter for Android. Built with React Native, Expo, and FFmpeg.

## Features
- 📸 **Image Conversion:** JPG, PNG, WEBP, BMP, HEIC, TIFF
- 🎵 **Audio Conversion:** MP3, WAV, M4A, AAC, FLAC, OGG, OPUS
- 🎬 **Video Conversion:** MP4, MOV, MKV, AVI, WEBM, 3GP
- 🎞️ **Video to GIF:** Custom time selection
- 🔊 **Audio Extraction:** Extract audio from video
- 🔇 **Silent Video:** Remove audio from video
- 🔒 **100% Offline:** Your files never leave your device.

- React Native & Expo (SDK 57)
- TypeScript
